# ProveMe

AI 없이, 실제 세무사 1차 기출문제를 60초 안에 풀 수 있어? 5문항, 문항당 60초의 재미용 챌린지 웹이에요.

재미용 챌린지예요. 실력을 보증하지 않으며 한국산업인력공단·한국교육과정평가원과 무관합니다.

made by brightiny9

## 로컬 실행

```sh
python3 -m http.server 8000
# http://localhost:8000/
```

## 문제 풀

`questions.json`: 2025년 제62회 세무사 1차 1교시 A형 재정학 25문항. 문제지와 최종정답은 Q-Net 세무사 자료실(한국산업인력공단, 공공누리 제1유형)에서 받았어요. 문항을 추가할 때는 2014년 이후 자료만, 제3자 저작물을 인용한 지문은 빼고, 공식 최종정답과 대조해요.
